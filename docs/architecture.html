Prototype outcome — source-data-blocked
654 passages built; only 39 (6%) paddy-relevant and 0 disease-specific dosage/PHI hits. Retrieval returns generic tables at distance >0.66. Verdict: the MARDI BPTM corpus does not carry checkable per-product dosage/PHI facts — a legitimate, reportable finding, not a code bug. Reviewer caches to data/reviews_grounded/ and never mutates source YAML. Tests: test_grounded_review.py (11/11).

Layer status

LayerTypeStatusRole in the safety boundary
Layer 1 — Compliance deterministic code enforced · live Fail-closed gate. Orchestrator blocks embed on any REJECT and exits non-zero. The load-bearing safety boundary.
Layer 1b — Professor LLM reviewer advisory Domain-expert critique for entry quality. Non-blocking; informs authors, does not gate serving.
Layer 2 — Grounded RAG + LLM built · data-blocked Quotes source passages to ground claims. Fully built & tested; repurposed for narrative until a citable dosage/PHI dataset exists.
Layer 3 — Ensemble multi-model out of scope Deferred. Not part of the prototype.
