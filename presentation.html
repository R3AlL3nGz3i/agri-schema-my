Malaysia has 440,000+ smallholders.

  • ⚠Wrong treatment = lost harvest. A misidentified fungal vs. bacterial pathogen means the wrong compound — and total crop failure.
  • ⚠Banned chemical = rejected export. Malaysia's MY_banned list is real. An LLM doesn't know it exists.
  • ⚠Wrong dosage = residue violation. PHI (pre-harvest interval) days are the difference between safe produce and a food-safety prosecution.
  • 📄The knowledge exists — but it's locked in MARDI PDF bulletins, invisible to every AI system and agritech app ever built.

Nobody has filled this gap.

What we built

📦

Dataset

23 validated YAML entries, 9 Malaysian crops. Each entry: pathogen ID, symptom severity stages, dosed treatment protocol, MY_approved badge, MARDI/DOA citation, confidence score.

⚙️

Multi-Agent Pipeline

Seed Generator → Schema Validator (CI) → Professor Agent (AI agronomist, PASS/FLAG/REJECT) → Vector Embedder (ChromaDB). Agents generate; agents audit.

🔌

Grounded API

FastAPI /diagnose endpoint. Symptom text (English or Bahasa Melayu) → Chroma semantic search → Claude-ranked diagnosis card with regulatory badge + MARDI citation.
